# 💻 Fresh CLI & Developer Tooling Manual

Fresh comes equipped with first-class developer tooling built into the unified `fresh` command-line executable. No third-party linters, formatters, or project managers are required.

---

## 1. Execution Methods

You can invoke Fresh in three equivalent ways:

1. **Global CLI command** (after `pip install fresh-lang` or binary installation):
   ```bash
   fresh <subcommand> [options]
   ```
2. **Python Module invocation** (always reliable across platforms):
   ```bash
   python -m fresh <subcommand> [options]
   ```
3. **Local Windows Wrappers** (in the repository root):
   ```powershell
   .\fresh.ps1 <subcommand> [options]   # PowerShell
   fresh.cmd <subcommand> [options]     # Command Prompt
   ```

---

## 2. CLI Subcommands Reference

### `fresh run <file.fresh> [flags]`
Executes a Fresh source file on the stack-based Virtual Machine or compiles it via the C backend.

**Inspection & Compilation Flags**:
- `--dump-tokens`: Prints the scanned token stream (token type, lexeme, line, column).
- `--dump-ast`: Prints the formatted Abstract Syntax Tree representation.
- `--disassemble`: Prints the disassembled VM bytecode instructions and constant pool.
- `--emit-c`: Transpiles the source file into standalone C99 code and prints it to stdout.

**Examples**:
```bash
# Run on VM
fresh run examples/01_fibonacci.fresh

# View generated bytecode
fresh run examples/01_fibonacci.fresh --disassemble

# Inspect transpiled C code
fresh run examples/01_fibonacci.fresh --emit-c
```

---

### `fresh check <file.fresh>`
Runs lexical scanning, parsing, module resolution, and static type checking without executing the program. Exits with code `0` if valid, or code `1` with source diagnostic underlines if semantic errors are detected.

```bash
fresh check main.fresh
```

---

### `fresh fmt <file.fresh> [--check]`
Formats a Fresh source file in-place according to canonical style rules (2-space indent, normalized spacing around operators, standard brace placement).

**Flags**:
- `--check`: Does not overwrite the file. Exits with code `1` if formatting changes are required, or `0` if cleanly formatted.

```bash
# Format file in-place
fresh fmt main.fresh

# CI validation check
fresh fmt --check main.fresh
```

---

### `fresh init <project-name> [--dir <path>]`
Scaffolds a new, production-ready Fresh project directory.

```bash
fresh init my_service
```

**Generated Directory Structure**:
```text
my_service/
├── fresh.toml             # Project manifest & build configuration
├── src/
│   └── main.fresh         # Application entrypoint
└── tests/
    └── test_main.fresh    # Integration tests
```

---

### `fresh build [project-path]`
Reads `fresh.toml` from the specified project directory, validates dependencies, transpiles the project to C, and invokes the host C compiler (`gcc`, `clang`, or `cl.exe`) to generate an optimized native binary inside `<project>/build/`.

```bash
fresh build my_service
# Output executable: my_service/build/my_service.exe
```

---

### `fresh test [path]`
Runs the automated test suite within the specified project or test directory.

```bash
fresh test
```

---

### `fresh repl`
Starts an interactive Read-Eval-Print Loop for rapid prototyping and expression evaluation.

```text
Fresh v0.1.0 Interactive REPL
Type '.exit' to quit, '.help' for commands.
>>> let x = 40 + 2;
>>> println("Result:", x);
Result: 42
```

## 3. Project Manifest (`fresh.toml`)

Projects initialized with `fresh init` include a declarative configuration manifest:

```toml
[package]
name = "myapp"
version = "0.1.0"
entry = "src/main.fresh"

[build]
opt_level = 2
c_compiler = "gcc"
out_dir = "build"
```

## 4. VS Code Extension

Fresh includes a custom VS Code extension located in `vscode-extension/`:
- **Syntax Highlighting**: Grammar covering keywords, strings, types, and numbers.
- **Bracket Matching**: Auto-closing braces `{}` and parentheses `()`.
- **Custom File Icons**: Official Fresh branding for `.fresh` files.
- **1-Click Execution**: Integration with VS Code tasks to run and build with a single keystroke.

### Installation:
```bash
code --install-extension vscode-extension/fresh-vscode-0.1.0.vsix
```
